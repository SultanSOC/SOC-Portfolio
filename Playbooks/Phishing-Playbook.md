# Playbook: Phishing Email Response

## 1. Check the Email
- Review sender address
- Check links and attachments
- Look for suspicious wording or impersonation

---

## 2. Check User Activity
Determine if the user:
- Opened the email
- Clicked the link
- Downloaded a file
- Entered credentials

---

## 3. Investigate
- Search SIEM for similar emails
- Review endpoint activity
- Check URLs/domains with threat intelligence

---

## 4. Contain
If malicious:
- Block sender/domain
- Remove email from inboxes
- Isolate affected device if needed

---

## 5. Escalate
Escalate if:
- User clicked link
- Malware executed
- Credentials exposed
- Multiple users affected

---

## 6. Recover
- Reset passwords if needed
- Monitor device and account activity
